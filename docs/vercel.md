# Vercel Deployment

## POS Project

- Root Directory: `apps/pos`
- Framework: Next.js
- Install Command: `npm install`
- Build Command: `npm run build`
- Output: `.next`

Configure the existing POS environment variables in this Vercel project.

## Admin Project

- Root Directory: `apps/admin`
- Framework: Next.js
- Install Command: `npm install`
- Build Command: `npm run build`
- Output: `.next`

Configure the existing Admin environment variables in this Vercel project. Keep database URLs, service-role keys, and admin secrets server-only.

## Domains

- `app.vernex.in` -> POS project
- `admin.vernex.in` -> Admin project
